# Импорт документов: архитектура и серверный контракт

## Что делает клиент (реализовано)
1. **Сканер** (`src/screens/Scanner.tsx`): камера с автообнаружением листа, вспышкой и автосъёмкой; фото; PDF (многостраничный); ручная правка углов; повтор страницы; оценка качества (размытость, темнота, блики, тени).
2. **Обработка изображения** (`src/scanner/imaging.ts`): поиск границ листа, коррекция перспективы (гомография), выравнивание освещения, контраст, резкость.
3. **OCR** (`src/scanner/engine.ts`): интерфейс `OcrEngine` — движок заменяем. Реализация — Tesseract.js, русская модель и ядро лежат локально (`public/tesseract`, копируются скриптом `scripts/copy-ocr.mjs`), интернет не нужен.
4. **Разбор** (`src/scanner/pipeline.ts`): тип документа (технологическая / калькуляционная / обе / неизвестно) → шапка → таблица по линиям сетки, ячейка за ячейкой (числа читаются отдельным проходом; проблемная ячейка перечитывается с увеличением) → столбцы определяются по заголовкам.
5. **Проверка** (`src/scanner/validate.ts`, `numbers.ts`): точная десятичная арифметика (BigInt), суммы столбцов, количество × цена, нетто ≤ брутто, выход vs итог. Вычисленное хранится отдельно от прочитанного.
6. **Экран проверки**: оригинал рядом с распознанным, цвета уверенности (зелёный/жёлтый/красный), правка, добавление/удаление ингредиентов, перечитывание строки. Сохранение — только по кнопке; при красных полях нужно подтверждение.
7. **Хранение на устройстве**: карточка (`Recipe.scan`, `Ingredient.original`) — localStorage; исходные фото — IndexedDB (`src/lib/imports.ts`).

## Правила точности
- Исходные значения никогда не округляются и не заменяются; запятая сохраняется.
- Нечитаемая ячейка остаётся пустой и красной — нулём не заполняется.
- Если распознан «.» вместо «,» — значение остаётся как прочитано и помечается для проверки.

## Серверный контракт (не реализован в этом репозитории — клиент без авторизации)
`POST /api/recipes/import-draft` (роль admin/manager) — тело: `Recipe` из клиента + `scan` + `images[]` (jpeg). Сервер обязан сохранять `status: "draft"` и никогда не публиковать автоматически. Рекомендуемая коллекция MongoDB `recipe_imports`: `{ _id, recipeId, docType, engine, header, rows[{original, computed}], images[], createdBy, createdAt, status }`.
